# 📊 Customer Churn Prediction

## 📌 Project Overview
Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a company's service or continue using it.

The project analyses customer information, service usage, and behavioural patterns to identify customers who are at risk of leaving. This helps businesses improve customer retention and reduce customer loss.

## 🎯 Objectives
- Predict customer churn using Machine Learning.
- Identify important factors influencing customer churn.
- Analyse customer behaviour and patterns.
- Help businesses improve customer retention.
- Build an accurate and reliable prediction model.
